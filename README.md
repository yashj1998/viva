# ViVA E-Commerce Storefront

ViVA (Live Better) Multi-Category E-Commerce Storefront built with Node.js, Express, MongoDB, EJS, and Tailwind CSS.

## Features

- Multi-category product catalog
- Shopping cart and wishlist functionality
- Admin and seller dashboards
- User authentication
- Responsive design with Tailwind CSS

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up environment variables in `.env`:
   - `PORT`: The port the server will run on (e.g., 3000, 3002)
   - `MONGODB_URI`: Your MongoDB connection string
   - `SESSION_SECRET`: Secret key for session management
   - `ADMIN_EMAIL`: Default admin email
   - `ADMIN_PASSWORD`: Default admin password

3. Start the development server:
   ```bash
   npm run dev
   ```

4. The application will be available at `http://localhost:<PORT>`
